# KI-Werkstatt

Die KI-Werkstatt gehört zum Online-Kurs **KI-Kompass am HPI** (HPI d-school). Du nimmst eine eigene Aufgabe und gehst mit ihr durch vier Stationen: Kompass-Karte, Entscheidungsspiel, Assistenz und Sparring. Am Ende hast du eine begonnene Kompass-Karte und mindestens zwei kleine Versuche hinter dir.

**Zur Werkstatt:** https://d-sesam.github.io/ki-werkstatt/

Hinweise:

- Die Seite läuft komplett im Browser. Was du einträgst, bleibt auf deinem Gerät und wird nicht an einen Server geschickt.
- Die Versuche machst du in ChatGPT; die Werkstatt erzeugt dafür die Aufträge zum Kopieren.
- Welche Werkzeuge und Daten am HPI erlaubt sind, regelt die KI-Richtlinie des HPI.
